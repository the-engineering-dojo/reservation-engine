# 🤝 Collaborate on Reservation Engine

[← Project home](README.md) · [🥋 Organization guide](https://github.com/the-engineering-dojo/.github/blob/main/CONTRIBUTING.md)

This repository is a **learning experiment**, not a race to produce a feature-heavy demo.

### 👥 How to help right now

- Review the [domain assumptions](docs/domain-model.md) and propose counterexamples.
- Comment on [ADR-0001](docs/adr/0001-modular-monolith-first.md).
- Propose a concrete failure scenario or [challenge](docs/challenges.md).
- Improve a diagram, definition, or explanation.
- Pair with a teammate to write a hypothesis before proposing implementation.

### 🔎 What a review should ask

1. Which invariant are we protecting?
2. What alternatives did we consider?
3. What failure could falsify this claim?
4. How would the experiment be reproduced?
5. What did we choose **not** to implement?

### 🚦 Current scope

**Documentation and planning only.** No application code, infrastructure manifests, or benchmark results until the team explicitly decides to implement a lab.
