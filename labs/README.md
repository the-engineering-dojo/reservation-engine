### 👥 Team ritual

1. Everyone writes a prediction.
2. One person explains an approach; another challenges it.
3. Reproduce the result using a shared scenario.
4. Discuss what would make the result invalid.
5. Capture a five-minute summary and links to evidence.

Use the [handbook challenge template](https://github.com/the-engineering-dojo/engineering-handbook/blob/main/templates/challenge.md).
